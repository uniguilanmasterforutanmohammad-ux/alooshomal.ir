# نمونه پیامک‌های بانکی برای تست

پارسر به‌صورت محافظه‌کارانه عمل می‌کند. نمونه‌های زیر باید تشخیص داده شوند:

```text
بانک ملی
واریز به حساب
مبلغ: 4,500,000 ریال
کارت مقصد: 6037******5678
شماره پیگیری: 998877
```

```text
بانک ملت
واریز: 450,000 تومان
به کارت 6104-3377-1234-5678
```

```text
بانک سامان
مبلغ 1,250,000 ریال به حساب شما واریز شد.
حساب مقصد: 6219******1234
```

نمونه‌هایی که **نباید** ارسال شوند:

```text
برداشت از حساب شما: 500,000 ریال
خرید موفق از فروشگاه
رمز یک‌بارمصرف: 123456
```

برای تست روی امولاتور:

```bash
adb emu sms send 1000 "بانک ملی
واریز به حساب
مبلغ: 4,500,000 ریال
کارت مقصد: 6037******5678
شماره پیگیری: 998877"
```
