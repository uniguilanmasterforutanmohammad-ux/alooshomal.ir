# فایل‌های ایمپورت شهر و محله / مشاغل

این پوشه دو فایل نمونه برای بخش «تنظیمات ← شهرها و کسب‌وکارها» در پنل مدیر
(`/admin?section=settings-taxonomy`) دارد. هر دو از داده‌های همین نصب (شهرهای
فعال، محله‌های ذخیره‌شده و تاکسونومی مشاغل) ساخته شده‌اند و با همان قالب
دوباره قابل ایمپورت‌اند. در خود پنل هم دکمه‌ی «دانلود فایل فعلی» همین خروجی را
از وضعیت لحظه‌ای دیتابیس می‌سازد.

## `cities-neighborhoods.csv`

ستون‌ها: `شهر,محله`

- هر ردیف یک محله از یک شهر است؛ شهر تکرار می‌شود.
- برای شهری که محله ندارد، فقط یک ردیف با ستون محله‌ی خالی بنویسید.
- شهری که در فایل باشد و در سایت نباشد ساخته می‌شود؛ شهر و محله‌ی موجود
  دوباره ساخته نمی‌شوند (ایمپورت تکرارپذیر است).

## `business-taxonomy.csv`

ستون‌ها: `کسب و کار,زیردسته,زیرشاخه`

- ستون اول «دسته اصلی» است و در فهرست عمومی/فیلترها دیده می‌شود.
- ستون دوم «زیردسته» و ستون سوم «زیرشاخه» است.
- ردیف می‌تواند فقط تا زیردسته برود؛ ستون زیرشاخه را خالی بگذارید.
- اگر یک زیردسته چند زیرشاخه دارد، برای هر زیرشاخه یک ردیف بنویسید.

هر دو فایل CSV با BOM هستند تا اکسل حروف فارسی را درست نشان دهد؛ ورودی اکسل
(`.xlsx`) با همین نام ستون‌ها هم پذیرفته می‌شود. پیش از هر تغییر، دیتابیس
به‌صورت خودکار snapshot می‌شود (نگاه کنید به `docs/BACKUP-RESTORE.md`) و هیچ
ایمپورتی رکورد موجود را حذف نمی‌کند.
