آیا گوگل کارت‌ویزیت‌ها و بیولینک‌ها را می‌بیند؟ چگونه خودم چک کنم؟

پلتفرم آلوشمال — alooshomal.ir

تاریخ: ۲۵ مهر ۱۴۰۵

منبع کد: docs/SEO-CRAWLER-CHECK.md

پاسخ کوتاه

بله. همه‌ی کارت‌ویزیت‌ها و بیولینک‌های منتشرشده به‌صورت خودکار در sitemap.xml فهرست می‌شوند و محتوای هر صفحه به‌صورت HTML سمت سرور (SSR) در اختیار خزنده قرار می‌گیرد؛ نیازی به اجرای جاوااسکریپت نیست.

پرسشپاسخکجای کد
لیست کامل صفحات قابل‌خزش؟ sitemap.xml apps/web/app/sitemap.ts + apps/api/src/seo/
اجازه‌ی خزش و مسیرهای ممنوع؟ robots.txt apps/web/app/robots.ts
محتوای هر کارت قابل‌خواندن است؟ بله، SSR صفحات [slug]/page.tsx
داده‌ی ساخت‌یافته؟ JSON-LD صفحات جزئیات
لینک‌های داخلی دایرکتوری؟ لینک واقعی <a href> Directory*Content.tsx

چطور خودم هر لحظه چک کنم

همه‌ی دستورها روی دامنه‌ی واقعی قابل اجرا هستند (نیاز به نصب چیزی نیست):

# ۱) تعداد کل آدرس‌های قابل‌خزش
curl -s https://alooshomal.ir/sitemap.xml | grep -c '<loc>'

# ۲) فقط کارت‌ویزیت‌ها
curl -s https://alooshomal.ir/sitemap.xml | grep -c 'business-cards/'

# ۳) فقط بیولینک‌ها
curl -s https://alooshomal.ir/sitemap.xml | grep -c 'biolinks/'

# ۴) محتوای یک کارت با «دید گوگل» (بدون اجرای JS)
curl -A "Mozilla/5.0 (compatible; Googlebot/2.1)" \
  https://alooshomal.ir/business-cards/<slug>

# ۵) مجوز خزش و آدرس نقشه‌ی سایت
curl -s https://alooshomal.ir/robots.txt

# ۶) کد پاسخ یک صفحه برای خزنده (باید 200 باشد)
curl -s -o /dev/null -w '%{http_code}\n' \
  -A "Googlebot" https://alooshomal.ir/business-cards/<slug>

نکته: در محیط توسعه، https://alooshomal.ir را با http://localhost:3000 جای‌گزین کن.

فهرست کردن همه‌ی آدرس‌ها به‌صورت متن

# همه‌ی کارت‌ویزیت‌ها، یک در هر خط
curl -s https://alooshomal.ir/sitemap.xml \
  | grep -oE '<loc>[^<]+business-cards/[^<]+</loc>' \
  | sed -E 's#</?loc>##g'

# همه‌ی بیولینک‌ها
curl -s https://alooshomal.ir/sitemap.xml \
  | grep -oE '<loc>[^<]+biolinks/[^<]+</loc>' \
  | sed -E 's#</?loc>##g'

ابزارهای رسمی گوگل

  • Google Search Console → URL Inspection: همان HTML خامی که گوگل دیده را نشان می‌دهد.
  • Rich Results Test: اعتبار JSON-LD و امکان نمایش نتایج غنی.
  • Lighthouse / PageSpeed: بخش SEO (قابل‌خزش بودن و متادیتا).

آیا کارت/بیولینک جدید خودکار وارد لیست می‌شود؟

بله. مکانیزم کاملاً خودکار است و هیچ لیست دستی‌ای وجود ندارد.
  1. apps/web/app/sitemap.ts هنگام درخواست، اندپوینت GET /seo/sitemap را صدا می‌زند.
  2. apps/api/src/seo/seo.service.ts با یک کوئری زنده از دیتابیس، ردیف‌های status = APPROVED و isPublished = true را برمی‌گرداند.
  3. پس هر آیتم جدید که منتشر و تأیید شود، در درخواست بعدی حاضر است؛ و هر آیتم غیرفعال/حذف‌شده، خودکار حذف می‌شود. 
# تست سریع زنده از سمت API
curl -s http://localhost:3001/api/seo/sitemap \
  | python3 -c "import sys,json;print(len(json.load(sys.stdin)['data']),'entries')"

نکته‌ی مهم: تأخیر کش

نقشه‌ی سایت revalidate = 3600 دارد؛ یعنی تا حداکثر یک ساعت ممکن است نسخه‌ی کش‌شده سرو شود. خزنده‌ی گوگل هم بازدید دوره‌ای خودش را دارد و کارت جدید را در بازدید بعدی ایندکس می‌کند (نه فوری).

سقف تعداد

MAX_ROWS = 20_000 سقف هر نوع ردیف در هر پاسخ است. با عبور از این عدد باید نقشه‌ی سایت به چند فایل صفحه‌بندی شود (sitemap index).

چک‌لیست تغییر مکانیزم سئو

  • آیا ردیف‌های غیرمنتشرشده/رد‌شده از sitemap خارج می‌مانند؟
  • آیا صفحات ناموجود همچنان noindex می‌خورند؟
  • آیا canonical و Open Graph به‌روز است؟
  • آیا لینک‌های دایرکتوری در HTML سمت سرور باقی مانده‌اند؟
  • آیا History-Agent.md و نسخه‌ی apps/web/lib/version.ts به‌روز شده؟
