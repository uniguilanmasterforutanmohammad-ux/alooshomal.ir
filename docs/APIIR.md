# سرویس‌های استعلام api.ir

این سند نحوه‌ی اتصال پلتفرم به وب‌سرویس‌های **api.ir** را توضیح می‌دهد.
مستندات رسمی (Scalar): <https://s.api.ir/scalar/v1> و قرارداد ماشین‌خوان
OpenAPI: <https://s.api.ir/openapi/v1.json>.

> **هزینه:** هر فراخوانی واقعی از اعتبار حساب api.ir کم می‌شود. دکمه‌ی
> «آزمایش» در پنل یک درخواست **واقعی و هزینه‌زا** است.

## اتصال

| مورد | مقدار |
| --- | --- |
| آدرس پایه | `https://s.api.ir` (قابل تغییر با `APIIR_BASE_URL`) |
| احراز هویت | هدر `Authorization: Bearer <API_KEY_API.IR>` |
| قالب | JSON (RESTful، همه‌ی مسیرها `POST`) |

کلید فقط سمت سرور خوانده می‌شود و هرگز به مرورگر نمی‌رود. مقدار آن را در
`.env` سرور قرار دهید:

```env
API_KEY_API.IR=<key>
APIIR_BASE_URL=https://s.api.ir
```

نام متغیر همان است که در پنل api.ir نمایش داده می‌شود (با نقطه). چون
`ConfigService.get()` نقطه را جداکننده‌ی مسیر می‌داند، کلید مستقیماً از
`process.env['API_KEY_API.IR']` خوانده می‌شود؛ نام جایگزین `APIIR_TOKEN` هم
پذیرفته می‌شود. در `docker-compose.yml` این متغیر به‌صورت pass-through از
`.env` به کانتینر API داده می‌شود.

اگر کلید تنظیم نشده باشد، پنل «api.ir» وضعیت «تنظیم نشده» را نشان می‌دهد و
فراخوانی‌ها با خطای ۵۰۳ رد می‌شوند.

### قالب پاسخ

```json
{ "data": { ... }, "success": true, "code": 0, "message": "موفق" }
```

`success` موفقیت درخواست را مشخص می‌کند؛ `message` و `code` برای نمایش خطا
استفاده می‌شوند و پاسخ خام در پنل نشان داده می‌شود.

## فهرست سرویس‌ها

فایل `apps/api/src/apiir/apiir.constants.ts` **تولیدشده** است و از اسپک رسمی
api.ir ساخته می‌شود. برای به‌روزرسانی پس از تغییرات api.ir:

```bash
python3 scripts/sync_apiir_catalog.py                # دریافت اسپک از سرور
python3 scripts/sync_apiir_catalog.py --spec spec.json   # از فایل محلی
```

گروه‌های پنل: احراز هویت، بانکی، شرکت و کسب‌وکار (شامل «استعلام اعتبار مجوز
شغلی/پروانه کسب»)، خودرو و گواهینامه، پستی/آدرس/آی‌پی، قبض و شارژ،
پیامک/تماس و ابزار.

### استعلام اعتبار مجوز شغلی (پروانه کسب)

`POST /api/sw1/License` با بدنه‌ی `{ "trackingCode": "BL123456" }`. خروجی
شامل عنوان مجوز، کد پیگیری، صادرکننده، نام کامل، کد ملی، تاریخ صدور/انقضا،
استان/شهر، آدرس و کدپستی است. نمونه فراخوانی برنامه‌نویسی:

```ts
// در سرویس‌های سمت سرور
const result = await this.apiir.inquiryLicense('BL123456');
if (result.ok) console.log(result.data);
```

## فعال‌سازی ماژولار

پنل مدیریت → «api.ir (استعلام)» همه‌ی سرویس‌ها را گروه‌بندی‌شده نشان می‌دهد.
هر سرویس یک کلید تنظیمات مستقل دارد:

```
apiir.service.<key> = true | false
```

- پیش‌فرض همه‌ی سرویس‌ها خاموش‌اند و با سوییچ پنل روشن می‌شوند.
- سمت سرور، `ApiIrService.assertServiceEnabled(key)` هنگام استفاده اعمال
  می‌شود؛ بنابراین خاموش‌بودن سوییچ حتی با فراخوانی مستقیم هم جلوی درخواست را
  می‌گیرد.
- دکمه‌ی «آزمایش» در پنل، سرویس را حتی وقتی خاموش است یک‌بار صدا می‌زند
  (`force`) و پاسخ خام api.ir را نشان می‌دهد.
- هر سرویس یک قیمت اختیاری (`apiir.price.<key>`) برای شارژ آینده‌ی کاربران
  دارد؛ نمایش/کسر هزینه زمانی فعال می‌شود که سرویس به کاربران عرضه شود.

## مسیرهای ادمین

| مسیر | توضیح |
| --- | --- |
| `GET /admin/apiir/services` | فهرست سرویس‌ها + وضعیت فعال و قیمت |
| `PATCH /admin/apiir/services/:key` | فعال/غیرفعال و تعیین قیمت |
| `POST /admin/apiir/services/:key/test` | فراخوانی آزمایشی (هزینه‌زا) |

## فایل‌های مرتبط

- `apps/api/src/apiir/apiir.constants.ts` — فهرست تولیدشده‌ی سرویس‌ها.
- `apps/api/src/apiir/apiir.service.ts` — کلاینت و سوییچ‌ها.
- `apps/api/src/apiir/apiir.controller.ts` — مسیرهای ادمین.
- `apps/web/components/admin/AdminApiIr.tsx` — پنل مدیریت «api.ir».
- `scripts/sync_apiir_catalog.py` — تولید فهرست از اسپک رسمی.
